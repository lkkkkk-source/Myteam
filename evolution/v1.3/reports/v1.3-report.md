# MyTeam Project Workspace & Collaboration Layer — v1.3 Report

> 阶段：v1.3 · **MyTeam Project Workspace & Collaboration Layer**
> 目标：建立 **Agent Workspace Runtime**，为多 Agent 协作提供隔离工作区、变化追踪、checkpoint、merge 治理、artifact 关联：`Agent → Workspace → Change Tracking → Review → Quality Gate → Merge → Artifact`。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（workspace 层 + 多 Agent 隔离 + checkpoint/merge/artifact + CLI；9 用例测试 40/40 PASS）

## 1. 四层分离（强制）

**Workspace=工作环境 / Execution=执行过程 / Memory=元信息 / Artifact=正式产物**，四者独立不合并（ws-5）。

## 2. Workspace 层（`platform/workspace/`）

- `workspace-schema.yaml`：字段（workspace_id/task_id/agent/team/branch/status/snapshot_ref）+ 7 状态机（created→initialized→active→checkpointed→reviewing→merged→archived）+ **7 不变量（ws-1~ws-7）** + forbidden_fields。
- `workspace-policy.yaml`：每复杂任务独立 workspace；Agent workspace-local；高风险前 checkpoint；权限不自动改。
- `workspace-manager.yaml`：create→track→checkpoint→review→merge→artifact→archive 编排（人工触发）。
- `agents/agent-workspace-schema.yaml`：权限矩阵（developer 改源码；**reviewer/architect changes_allowed=none**）。
- `snapshots/checkpoint-schema.yaml`：连 Recovery，只增不删。
- `changes/change-record-schema.yaml`：每次修改来自 EE-*（execution_ref）。
- `merge/merge-policy.yaml`：Review→Quality→Approval→Merge，**automatic_merge=false**。
- `artifacts/artifact-link-schema.yaml`：merged change → artifact（带 quality_ref）。

## 3. 运行态（`.ai/context/workspace/`）

- `workspace-state.yaml`：WS-0001（developer/reviewing）、WS-0002（tester/active）、WS-0003（reviewer/只读），分支唯一、互不污染。
- `changes/`：CH-0001（developer/EE-0002）、CH-0002（tester/EE-0006）；reviewer 无 change。
- `snapshots/`：CP-0001、CP-0002（连 Recovery）。
- `merge/`：MG-0001 rejected（review 未过 → blocked）、MG-0002 merged（quality+approval 通过）。
- `artifact-links.yaml`：WS-0002/CH-0002 → artifact（带 quality_ref）。

## 4. 集成

- **Execution Engine**：Execution Request 必含 workspace_ref（ws-6）；change.execution_ref → EE-*；executor 只操作指定 workspace。
- **Recovery**：checkpoint 复用 `.ai/context/recovery/checkpoints/`，失败回滚。
- **Quality Gate**：merge 前必过 gate；artifact 关联带 quality_ref。
- **Memory**：只存 workspace/checkpoint pointer + merge status（不写全部内容，ws-5）。
- **CLI**：`myteam workspace status | list | trace ID | validate`（实测可运行）。

## 5. Agent 集成（3 个，其他不改）

- `project-health-agent.md`：+ 检查项 21「Workspace 一致性」（schema/permissions/checkpoint/merge state/artifact links/隔离与三层分离）。
- `engops-lead.md`：+「Workspace Infrastructure 生命周期」（create/checkpoint/merge 治理/artifact）。
- `project-manager-agent.md`：+「Workspace lifecycle 读取」（只读 status/list/trace）。
- 三者镜像到 opencode-global。

## 6. 测试结果

## 7. 硬性边界（强制）

禁止：自动 merge / Agent 绕过 workspace / 改他人 workspace / 自动删 checkpoint / workspace 替代 Memory / 替代 Artifact / 自动改权限 / 自动覆盖他人修改。

## 8. 基线确认

**Agent=30 · MCP=5 · Skill=26 · Workflow=8（保持不变）**

MyTeam 从 **Governed Agent Runtime** 升级为 **Collaborative Agent Development Platform**：完整链路 `User → Router → Team → Agent → Workspace → Scheduler → Action → Approval → Execution Engine → Change Tracking → Quality Gate → Merge → Artifact → Evolution` 全程受治理、隔离、可追溯、不自动越权。
