# MyTeam Debug & Trace Mode Layer — v1.4.1 Report

> 阶段：v1.4.1 · **MyTeam Debug & Trace Mode Layer**
> 目标：建立 Task Trace Runtime，提供一次任务的**完整生命周期视图**（12 层），解决"各层齐全但缺少全链路可查询视图"的问题。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（trace 层 + 12 层链路 + CLI；10 用例测试 36/36 PASS）

## 1. 定位

Trace 记录一次任务跨 12 层的生命周期链路（**pointer only**），提供 记录 / 查询 / 展示 / 审计。**不执行、不修复、不调度、不改状态**（tr-2）。Trace ≠ Memory ≠ Observability ≠ Collaboration ≠ Execution Ledger（tr-3，不替代）。

## 2. Trace 层（`platform/debug-trace/`）

- `trace-schema.yaml`：`trace_id/task_id/workflow_id/start_time/end_time/status/events[]/layers[]`；状态机 created→running→completed→failed→archived；**6 不变量（tr-1~tr-6）** + forbidden（auto_execute/auto_repair/auto_decision/auto_schedule）。
- `trace-event-schema.yaml`：`event_id/trace_id/timestamp/layer/source/event_type/reference/metadata`；12 层枚举；reference 只 pointer。
- `trace-policy.yaml`：采集 + 边界规则。
- `collectors/`：router / collaboration / workspace / execution / quality（各层产生 trace event）。
- `storage/trace-index.yaml` + `queries/trace-query-schema.yaml` + `reports/trace-report-schema.yaml`（含 trace metrics）。

## 3. 运行态（`.ai/context/debug-trace/`）

- `trace-index.yaml`：TR-0001（refund-feature，completed，12 层）。
- `events/TR-0001-events.yaml`：EV-0001~EV-0012，覆盖 router→team→agent→collaboration→workspace→action→approval→execution→quality→artifact→memory→evolution，每层引用真实来源、无代码。

## 4. 集成（增 trace_ref / pointer，不复制内容）

- **Collaboration（v1.4）**：message/handoff/decision 概念上增 trace_ref（collector 登记）。
- **Workspace（v1.3）**：change/checkpoint trace_ref；不保存代码。
- **Execution（v1.2）**：action/approval/execution ledger trace_ref。
- **Memory**：只存 trace pointer + 关键 decision（tr-6，不存完整 trace）。
- **Observability（v0.4.4）**：trace metrics（trace_complete_rate / missing_reference_count / avg_task_trace_duration），只分析不改行为。
- **CLI**：`myteam trace status | show TASK_ID | timeline TASK_ID | validate`（实测可运行）。

## 5. Agent 集成（3 个，其他不改）

- `engops-lead.md`：+「Debug & Trace 生命周期」。
