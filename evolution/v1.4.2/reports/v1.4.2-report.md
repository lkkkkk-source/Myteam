# MyTeam Runtime Safety & Production Guard Layer — v1.4.2 Report

> 阶段：v1.4.2 · **MyTeam Runtime Safety & Production Guard Layer**
> 目标：为 MyTeam Runtime 增加生产安全治理——资源限制 / 成本控制 / 超时控制 / 无限循环保护 / 高风险人工确认。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（safety 层全套 + CLI + trace 13 层扩展；10 用例测试 51/51 PASS）

## 1. 定位

Safety Layer **只限制风险**（safe-by-default）：不改 Router / Agent Selection / Model Routing / Execution Policy / Quality Gate；**不替代 Approval / Execution Engine**（sf-4）。只 检测 / 限制 / 阻断 / 升级人工确认。

## 2. Safety 层（`platform/runtime-safety/`）

- `safety-policy.yaml`：safe-by-default + 状态机（normal/warning/blocked/waiting-human）+ execution gate（allowed/warning/blocked/human_required）+ **6 不变量（sf-1~sf-7）** + forbidden（auto_override/auto_retry_forever/auto_escalate_permission/auto_expand_budget）。
- `risk-schema.yaml`：low/medium/high/critical → 判定；critical→human_required。
- `budget/`：token-budget（超限 waiting-human）+ cost-budget + budget-policy（token 200k/cost $5/warn 80%）。
- `limits/`：execution-limit（30m/retry 3/parallel 5）、retry-limit（同 task/action/execution max 3）、loop-detection（重复 action/失败/handoff → suspected-loop → blocked）、concurrency-limit。
- `timeout/timeout-policy.yaml`：execution 30m→Recovery；approval/human 超时只提醒。
- `escalation/human-escalation-policy.yaml`：critical/budget/repeated-failure/loop → human confirmation。
- `integrations/`：trace（layer=safety）+ execution（执行前读 status）+ action（safety_check_ref）。

## 3. 运行态（`.ai/context/runtime-safety/`）

- `safety-state.yaml`：token/cost budget + SF-0001~0007（budget normal / budget exceeded→waiting-human / retry→blocked / loop→blocked / timeout→blocked / critical→waiting-human / normal→allowed）+ execution gate（AP-0001 allowed / AP-0002 blocked / AP-0003 human_required）。
- `escalations.yaml`：ESC-0001~0003（production deploy / budget / repeated failure，均 pending 待人工确认）。

## 4. 集成

- **Trace（v1.4.1）**：safety decision → trace event（layer=safety），trace 链扩展为 **13 层**（+safety）。
- **Execution Engine（v1.2）**：执行前读 safety status（sf-5）；blocked→拒绝，human_required→待确认；Safety 不替代 ee-1/ee-2。
- **Action（v0.8）**：Action Proposal 增 safety_check_ref；blocked/waiting-human 不进 approved。
- **CLI**：`myteam safety status | check TASK_ID | budget TASK_ID | violations | validate`（实测可运行）。

## 5. Agent 集成（3 个，其他不改）
