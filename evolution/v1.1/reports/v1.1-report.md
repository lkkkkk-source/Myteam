## 1. 定位

`tools/myteam-cli/` 是 MyTeam 的命令行管理工具。用户体验：
```
myteam init → myteam status → myteam doctor → OpenCode 加载 MyTeam → 使用 Agent Organization
```
CLI **只管理 状态 / 验证 / 迁移 / 回滚**；不安装、不改 OpenCode、不执行任务。

## 2. 结构（`tools/myteam-cli/`）

```
package.json              # bin.myteam / version 1.1.0 / commands / isolation
bin/myteam.mjs            # Node 可运行入口（src/*.ts 的等价实现；TS 为规范源）
src/index.ts              # 命令分发
src/commands/             # init / status / doctor / validate / upgrade / rollback
src/services/             # plugin-service / registry-service / validation-service / migration-service
src/output/formatter.ts
tests/cli-test.ps1
```

## 3. 命令（实测输出）

| 命令 | 结果 |
|---|---|
| `myteam init` | ✓ plugin manifest / workspace / source path / runtime adapter → **MyTeam initialized**（no auto-install） |
| `myteam status` | **MyTeam v1.1** · Plugin ✓ loaded · Agents 30/30 · Teams 6 · MCP 5 · Skill 26 · Workflow 8 · Runtime healthy · Lifecycle loaded |
| `myteam doctor` | 10 项诊断全 ✓，overall: **healthy**（never auto-repairs；drift report-only） |
| `myteam validate` | agent(30/source/version) + mcp(5) + skill(26) + adapter + evolution 全 ✓ → **validation: PASS**（mismatch → FAIL exit 1） |
| `myteam upgrade --dry-run` | 生成 migration plan（detect→backup→plan→approval→apply→verify），**DRY-RUN 不 apply**，no production auto-upgrade |
| `myteam rollback` | 复用 Recovery + rollback-plan，`deletes_history: false`，手动恢复 |

## 6. 硬性边界（强制）

- CLI 只管理 状态 / 验证 / 迁移 / 回滚；禁止自动安装插件 / 自动改 OpenCode 配置 / 自动执行任务 / 自动选 Agent / 自动改 Prompt / 自动调 Model Routing。
- CLI 命令不写 `~/.config/opencode`（Case7 实测宿主 0 变更）；`upgrade` 默认 dry-run；`rollback` 不删历史。
