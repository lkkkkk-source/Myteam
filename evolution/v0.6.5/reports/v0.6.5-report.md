## 1. Agent 选择原因

- 选定 **java-developer**
- 理由：
  - 位于 Java Team（software-engineering domain），是核心执行 Agent，升级收益最大

## 最终目标达成

建立了 **Agent 持续进化机制**：

- 不是增加 Agent 数量（Agent 稳定在 30）
- 而是让已有 Agent 通过外部研究 → Proposal → 评审 → 升级 → Benchmark → 评估 → 合并持续提升
- 升级走 release 流程（engops-lead 负责）+ 一致性检查（health）+ 状态读取（PM）三层闭环
- 全程不自动安装、不自动替换、不复制外部内容（仅作参考 + 转写为本平台协议）
