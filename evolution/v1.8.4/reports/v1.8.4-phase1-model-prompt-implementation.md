## 2. Model Adapter（`runtime/model/`）

### 2.1 契约（`types.ts`）

| 类型 | 作用 |
|---|---|
| `ModelAdapter` | 唯一推理入口：`complete(req: ModelRequest): Promise<ModelResponse>` |
| `ModelRequest` | `{ prompt: ExecutionPrompt; expects: "text"\|"json"; signal?; timeout_ms? }` |
| `ModelResponse` | `{ ok; text; usage?; finish_reason; error_kind?; error_detail? }` |
| `AgentErrorKind` | 8 类归一错误，与设计 §8 对齐（model_error / timeout / invalid_response / context_overflow / cancel / tool_denied / tool_error / agent_error） |
| `ModelFinishReason` | `stop \| length \| tool_use \| error` |

> 抽象层**不出现任何厂商名 / 专属字段**，为后续真实适配器预留插槽。

### 2.2 NullModelAdapter（`null-adapter.ts`）

- **不联网**：无 `fetch` / `http(s)` / sdk；无网络出口。
- **无 Key**：不读 `process.env`、不落盘凭据。
- **确定性**：相同请求 → 相同响应（无随机、无时钟依赖）。
- **可解释**：`text` 模式回显 `goal`；`json` 模式输出 `{"kind":"answer","text":goal}`（合法 JSON）。
- **取消语义**：`signal.aborted` → `{ ok:false, error_kind:"cancel", finish_reason:"error" }`。
- **可注入**：构造函数可传 `responder`，仅为测试 / 装配定制文本（仍不涉及网络）。

### 2.3 测试（21/21 PASS）

1. **不联网（静态源码扫描）**：断言 `model/*.ts` 无 `fetch(`、无 `http/https` import、无 `axios/openai/anthropic/…`、无 `process.env`、无 `api_key/authorization/bearer`、无 `writeFile`。
2. **contract 正确**：text 模式 / json 模式 / 确定性 / 取消 / responder 注入 / 接口形状。

## 3. Prompt Assembly（`runtime/prompt/`）

### 3.1 产物（`types.ts`）

`ExecutionPrompt` 关键不变量：

| 字段 | 来源 | 不变量 |
|---|---|---|
| `prompt_source` | `instance.prompt_source` | **恒为路径引用，不含正文副本** |
| `identity` | `instance.agent/role` | 身份投影 |
| `goal` | `TaskInput.goal` | 任务段 |
| `capabilities[]` | `context.tools` | **只含 `allowed=true`** |
| `constraints` | `TaskInput` | **绝不注入 deny_paths / host_config / myteam_home** |
| `messages[]` | 装配 | `system`（身份/能力/约束/引用）+ `user`（goal） |
| `schema_version` | 常量 `1` | 装配标记 |

### 3.2 装配器（`assembler.ts`）

- `assemble(input: PromptAssemblyInput): ExecutionPrompt` —— **纯函数**，同输入同输出。
- `PromptAssembler` / `createPromptAssembler()` —— 无状态包装，便于依赖注入。
- **护栏 P-A1**：`prompt_source` 必须非空且与 `instance.prompt_source` 一致，否则抛错（防引用被篡改）。
- **禁则落实**：模块**完全不 import `node:fs`**；不读取、不复制、不落盘 prompt 正文。

### 3.3 测试（33/33 PASS）

1. **prompt_source 引用 Home**：明文断言 `=== instance.prompt_source`、指向 `/source/prompts/`、是路径而非内容。
2. **不复制 prompt 文件**：静态扫描无 `fs` / `copyFile` / `cp` / `writeFile` / `mkdir`；临时 workspace 装配前后目录为空；system 不含 prompt 正文标记（`## Role`）。
3. **workspace 注入**：`constraints.workspace` 正确且等于 `instance.workspace`。
4. **context 合并**：capabilities 仅 `allowed=true`（`bash` 被排除）、无 `deny_paths`/`host_config`/`myteam_home`/宿主路径泄漏、身份与 permissions 正确、goal 入 user 消息。
5. **多 project 隔离**：alpha/beta 两 workspace 的 workspace / goal / memory_ns 互不串扰，无交叉泄漏。
6. **额外护栏**：篡改 `prompt_source` 触发抛错。
