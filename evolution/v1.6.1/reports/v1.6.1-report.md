# MyTeam Agent Runtime Adapter — v1.6.1 Report

> 阶段：v1.6.1 — **Agent Runtime Adapter**
> 目标：在 Tool Bridge 之外新增 adapter 层，实现 AgentDefinition（静态定义，读自 MyTeam Home）
> 与 AgentRuntimeInstance（运行实例，投影到 `<project>/.team/runtime/agent-instance/`）。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（不变）。
> 状态：完成，adapter 3 步（create/initialize/bind）+ 持久化 + 18/18 PASS。

## 1. 定位

Adapter 层只做**定义投影 + 实例生命周期 + 持久化**，不做执行。
- 明确禁止：Tool Bridge / OpenCode 工具调用、Execution State Machine、Trace Event Bus、Runner。
- 平台/静态定义：MyTeam Home（Source of Truth）；运行实例/状态：`<project>/.team/`。
- 不修改任何现有 prompt markdown；不复制 prompt；不写宿主 opencode 配置。

## 2. AgentDefinition Loader（`plugin/opencode/agent-loader.ts`）

输入：`myteam_home/source/prompts/**/*.md`（9 个 team 目录，共 30 个 prompt）。
输出 `AgentDefinition`：
- `name / team / role / responsibility[] / workflow[] / skills[] / capability_refs[] / prompt_path / prompt_rel`。
- 纯正则解析（无外部依赖），只读不写。
- `skills` 提取自 `## Related Skills` / `## Skills` 行内反引号项；
  `capability_refs` 提取自 `## Capabilities`（可为空数组，不强制）。
- `role` 取 `## Role` 段首行首句（可读描述，不切词）。

## 3. Agent Runtime Adapter（`plugin/opencode/agent-instance.ts`）

生命周期（本阶段只实现三个过渡态）：
| 步骤 | 函数 | 结果 |
|---|---|---|
| 2a | `create(def, res, execCtx)` | `status = "created"`：分配 id / workspace / memory_namespace / instance_dir |
| 2b | `initialize(inst)` | `status = "initialized"`：建立实例目录骨架 + memory 命名空间 |
| 2c | `bind(inst)` | `status = "bound"`：绑定 prompt_source/workspace/memory/permissions，校验 memory 归属 |

`AgentRuntimeInstance` 字段：`id, agent, role, prompt_source, workspace, memory_namespace, execution_id, permissions, status, instance_dir`。

便捷入口 `activateAgent()` = create → initialize → bind → persist。

## 4. 实例持久化（Step 3）

- 路径：`<project_root>/.team/runtime/agent-instance/<execution_id>/<agent>.yaml`。
- memory 命名空间：`<team_root>/memory/agents/<execution_id>/<agent>/`（按 execution + agent 隔离）。
- `renderInstanceYaml()` 自持 schema_version 1；`persist()` 原子写（tmp + rename）。
- `readInstanceFile()` 读回结构化实例。

## 5. 测试（`plugin/opencode/test/agent-instance.test.ts`）

覆盖 spec 要求的 5 场景，**18/18 PASS**：
1. 同一 Agent 在 A/B 两个项目运行 → 两个不同 `AgentRuntimeInstance`（不同 workspace）。
2. memory 路径按项目（execution+agent）隔离。
3. 两个不同 execution id → 两个实例。
4. MyTeam Home 完全未被修改（prompt 仍在 Home，实例文件不在 Home 下）。
5. 删除 `<project>/.team/runtime/` 后重新生成。

## 6. 不变量与隔离确认

- `prompt_source` 指向 Home，**不复制** prompt 到项目。
- 实例文件 / memory 命名空间均落在 `<project>/.team/**`，**绝不写 MyTeam Home 或宿主配置**。
- 宿主 `~/.config/opencode` 不变（bridge guard 维持）。
- 卸载插件后 `.team` 可整体删除，无残留。
