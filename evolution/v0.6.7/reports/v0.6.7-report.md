# Agent Prompt Evolution Execution — v0.6.7 Report

> 阶段：v0.6.7 · Evolution Knowledge Execution（升级经验知识层 + 跨 Team 复用）
> 目标：把升级经验沉淀为可复用资产（Pattern Registry + Evolution Knowledge），并首次完成**跨 Team 复用**（java → research），建立「持续进化」的长期知识闭环。
> 升级前基线：Agent=30 MCP=5 Skill=26 Workflow=8（不变）
> 状态：完成

## 1. Agent 选择原因

- 本阶段升级 **research-analyst**（research 部门，结论/建议输出型 Agent），复用 java 链已验证的升级经验。
- 理由：
  1. **跨 Team 复用验证**：v0.6.5 / v0.6.6 在 java 部门（developer / architect / reviewer / tester）证明了 PATTERN-001 evidence-based-output 稳定有效（平均 delta +5）。research-analyst 与 java-developer 同属「输出结论型 Agent」，v1 差距点为「论断无证据」——与 java 链升级前完全同型。
  2. **知识层需要实证载体**：Evolution Knowledge Layer 首次落地，必须用一个真实跨 Team 复用案例证明「经验可迁移、可追溯」，而非停留在理论登记。
  3. **低成本高确定性**：直接从 `evolution/patterns/pattern-registry.yaml` 选取已验证 PATTERN-001，无需重新研究 / 重新探索模式空间。
  4. **不新增 Agent**：仍保持 30 个 Agent，只是让 research-analyst 从 v1 → v2。

## 2. 本阶段机制扩展（vs v0.6.6）

- v0.6.6：多 Agent 批量升级（B-066-01，同部门 java）。
- v0.6.7：**跨 Team 复用（B-067-01，java → research）** + **知识层资产**：
  - 新增 `evolution/patterns/pattern-registry.yaml`（模式注册表：有效 / 失效 pattern + delta_quality + evidence）。
  - 新增 `evolution/knowledge/evolution-knowledge.yaml`（知识索引：经验来源、跨 Team 复用记录、下一步候选）。
  - 新增 `analytics/metrics/evolution-pattern-metrics.yaml`（模式有效性指标，接入 analytics）。
  - 升级流程前置一步：**「查知识层 → 有已验证模式则直接复用」**，避免每 Agent 从零研究。

## 3. Prompt 差异（research-analyst v1 → v2）

| 维度 | v1 | v2（v0.6.7，复用 PATTERN-001） |
|------|----|----|
| 论断来源 | 直接给结论，无出处 | 每条论断标注来源 / 依据（evidence-based-output） |
| 证据强度 | 凭感觉/记忆 | Strong hypothesis / Weak hypothesis 显式分级 |
| 反幻觉 | 无 guardrail | 无来源支持内容强制标记「无证据支持」 |
| 遗漏风险 | 单视角 | 显式空白清单（research gap） |
| 方向优先级 | 平铺 | 优先级分级（贡献/可行性/新颖性） |

来源类型：内部 java 链实证（BM-065-01 / BM-066-01）+ 外部参考（external/agency-agents 只读，仅参考不复制）。

## 4. Benchmark 结果（BM-067-01）

- 方式：对 research-analyst v1 vs v2 在「研究前沿分析」场景做结论可追溯性 / 反幻想 / 优先级分级 / 多源覆盖对比。
- 结果：
  - evidence-based-output（origin=java）在 research-analyst 上增量 **+6**，与 java 链实证区间（+4~+6）一致 → 跨 Team 复用稳定有效。
  - 四维全部提升至 5（v1：4 / 3 / 3 / 2 → v2：5 / 5 / 5 / 5）。
- 结论：**accept**，research-analyst 允许 source 端升级到 v2。
