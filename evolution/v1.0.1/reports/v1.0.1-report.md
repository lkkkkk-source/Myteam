# MyTeam OpenCode Plugin Wrapper — v1.0.1 Report

> 阶段：v1.0.1 · **MyTeam OpenCode Plugin Wrapper**（在 v1.0 Runtime Adapter & Deployment Governance 之上）
> 目标：将 MyTeam 转换为 **OpenCode Plugin**，实现宿主隔离，避免污染 OpenCode 原生环境。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（Plugin 封装 + 隔离测试 19/19 PASS；就地只读，未写宿主）

## 1. 核心原则

- **OpenCode = Host Runtime**；**MyTeam = Independent Plugin**。
- 分层：`OpenCode → MyTeam Plugin → MyTeam Platform Core`。
- 插件**就地只读**读取 MyTeam 仓库（source/ platform/ registry/ runtime/），**不复制文件**、不污染宿主。

```
OpenCode (Host Runtime)
   ↓
MyTeam Plugin (plugin/opencode/)
   ↓
MyTeam Platform Core (source/ · platform/ · evolution/version-registry · .ai/context/ — read-only)
```

## 2. Plugin 结构（`plugin/opencode/`）

| 文件 | 职责 |
|---|---|
| `manifest.yaml` | Plugin Manifest：`name / version(1.0.1) / entry / platform_version(v1.0) / capabilities / isolation` |
| `index.ts` | Plugin Entry：初始化 MyTeam → 加载 registry → 加载 agents → 初始化 runtime（只读聚合）+ 隔离守卫 + `myteam.status` 只读工具 |
| `loader.ts` | Loader：读取 source/ platform/ registry/ runtime/，`copiedFiles=0`、`readOnly=true`（**不复制**） |
| `bridge.ts` | Bridge：OpenCode API ↔ MyTeam Runtime（只读视图 + `guardHostWrite` 拦截写宿主） |
| `myteam-plugin.yaml` | Plugin Config：`workspace / context_path / enabled_features / isolation` |
| `README.md` | 使用说明 + 安装（手动引用，非自动） |
| `tests/isolation-test.ps1` | 隔离测试（Case1~5 + 不变量） |

对齐 OpenCode 插件模型：入口导出 `MyTeamPlugin(ctx)` 返回 hooks（`tool` / `tool.execute.before` / `event`），本地插件从 `~/.config/opencode/plugins/` 或项目 `.opencode/plugins/` 引用，**不修改宿主配置**。

## 3. 隔离机制

- **不复制**：`copy_files: false`；loader 就地读取，`copiedFiles=0`。
- **不写宿主**：`host_config_write: false`；`index.ts` 的 `tool.execute.before` + `bridge.ts` 的 `guardHostWrite` 拦截任何写 `~/.config/opencode` 的尝试。
- **不污染全局**：manifest `never_modify` 覆盖 opencode.json / provider / mcp / shell / bulk copy。
- **可逆**：`reversible: true`；插件从不写宿主，移除引用即卸载，OpenCode 恢复原状（无残留）。
- **无反向改 source**：runtime 不反向修改 source（延续 v1.0 铁律）。
