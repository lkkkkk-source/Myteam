# MyTeam Agent Collaboration Protocol Layer — v1.4 Report

> 阶段：v1.4 · **MyTeam Agent Collaboration Protocol Layer**
> 目标：建立 Agent Team 通信与协作层：`Agent → Message → Handoff → Decision → Resolution → Execution`。补齐此前依赖 handoff / memory / notes 而缺失的统一协作协议。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（协作协议 5 schema + 记录 + CLI；9 用例测试 35/35 PASS）

## 1. 四层边界（强制）

**Collaboration=通信 / Workspace=文件 / Memory=认知 / Execution=执行**，四者独立不合并（cl-4）。Collaboration 不替代 Memory / 不替代 Workspace / 不自动执行 / 不自动改 Prompt。

## 2. 协作协议（`platform/collaboration/`）

- `collaboration-schema.yaml`：`collaboration_id/task_id/participants/team/status`；状态机 created→active→waiting→resolved→archived；**7 不变量（cl-1~cl-7）** + forbidden_fields（auto_resolve/auto_execute/auto_delegate/auto_call_agent）。
- `message-schema.yaml`：type ∈ {information,request,response,handoff,decision,review,conflict}；**content 只存结论 + evidence_ref**（不存完整聊天/代码，cl-3）。
- `handoff-schema.yaml`：from/to/task_context/completed_work/remaining_work/constraints/evidence/acceptance。
- `decision-schema.yaml`：problem/options/selected_option/reason/impact/risk；high/critical 不自动做。
- `conflict-schema.yaml`：positions/resolution/resolver；**不自动解决**。
- `policies/collaboration-policy.yaml`：allowed（发消息/请求/handoff/decision/conflict）；forbidden（自动调 Agent/改任务目标/绕过 PM/批高风险/直接 Execution）。

## 3. 运行态（`.ai/context/collaboration/`）

- CO-0001（java team 协作会话）
- messages：MSG-0001 dev→tester(request) / MSG-0002 tester→dev(response) / MSG-0003 reviewer→dev(review)
- handoffs：HO-0001 architect→developer（约束：禁改 DB 结构）/ HO-0002 developer→tester（downstream AP-0002）
- decisions：DE-0001 退款独立表 / DE-0002 step-2 走 Recovery
- conflicts：CF-0001 reviewer reject → resolver=java-lead（人工裁决）

## 4. 集成

- **Workspace（v1.3）**：message.evidence_ref 引用 workspace_ref / change；不含完整代码。
- **Memory**：task-memory 只存 collaboration pointer + key decisions + unresolved（不存完整消息，cl-3/cl-4）。
- **Execution（v1.2）**：collaboration 只产生 request/decision/handoff → Action Proposal（HO-0002→AP-0002）→ Approval → Execution Engine（cl-1）。
- **CLI**：`myteam collaboration status | trace TASK_ID | conflicts | validate`（实测可运行）。

## 7. 硬性边界（强制）

禁止：Agent 自动调用 Agent / 自动解决冲突 / 自动改变任务目标 / 自动修改 Prompt / 自动执行 Action / Collaboration 替代 Memory / 替代 Workspace。
