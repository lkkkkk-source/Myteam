# MyTeam Controlled Execution Engine — v1.2 Report

> 阶段：v1.2 · **MyTeam Controlled Execution Engine**
> 目标：在 v0.9 Controlled Execution Interface（只有契约）之上，实现**受治理执行引擎**：`Approved Action → Execution Engine → Executor → Tool/MCP/Runtime → Result → Quality/Observability`。
> 基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（引擎 + 5 executor + permission/sandbox/queue/result + Bridge + CLI；8 用例测试 41/41 PASS；只执行治理通过请求）

## 1. 架构原则（三层分离）

**Context=记录状态 / Action=记录意图 / Execution=记录实际执行**，三者独立台账。
禁止 Agent 直接调用 Executor；正确：`Agent → Action Proposal → Approval → Execution Engine → Executor`。
Execution Engine **不负责**：决定任务 / 选择 Agent / 修改 Prompt / 自动批准 Action / 绕过 Governance。

## 2. Execution Engine（`platform/execution-engine/`）

- `engine-schema.yaml`：Execution Request 字段 + **7 不变量（ee-1~ee-7）** + 8 状态机（prepared→authorized→queued→running→completed|failed|cancelled→rolled_back）+ forbidden_fields（auto_execute/auto_approve/bypass_permission/skip_quality）。
- `execution-policy.yaml`：low=approved execution / medium=PM / high=human / **critical=proposal-only（不执行）**；禁止自动提权。
- `executor-registry.yaml` + `executors/`：**5 executor** — code（workspace-clone/medium）、shell（container/high）、mcp（temp-env，仅 5 个已登记 MCP）、test（temp-env）、browser（container/high，经 playwright）。
- `permission/execution-permission.yaml`：**permission ≠ action approval**（两独立状态，都满足才 running）；过期失效；approved_by=null → denied。
- `sandbox/sandbox-policy.yaml`：none/workspace-clone/temp-env/container；代码默认 workspace-clone，危险操作 container+human。
- `queue/execution-queue.yaml`：只记录不自动调度。
- `result/execution-result-schema.yaml`：output/artifacts/errors/quality_ref/observability_ref/recovery_ref。

台账：`.ai/context/execution-engine/engine-state.yaml`（EE-0001~0006）+ `execution-results.yaml`。

## 3. OpenCode Plugin 集成

`plugin/opencode/execution-bridge.ts`：`admitExecution`（只准入 approved action + granted permission + authorized）、`refuseActionGeneration`（Plugin 不生成 Action）、`guardExecutionTarget`（宿主写守卫，继承 v1.0.1 隔离）。index.ts 暴露只读 `myteam.execution.admit` 工具。

## 4. CLI 增强

`myteam execution status`（执行状态）/ `myteam execution trace TASK_ID`（Action→Approval→Execution→Result）/ `myteam execution validate`（executor registry / permission / sandbox / policy / forbidden 字段）—— 实测全部工作。

## 7. 硬性边界（强制）

只执行已治理通过的请求；禁止自动执行未批准 Action / Agent 绕过 Engine / 自动选 Executor / 自动提权 / 自动改 Sandbox Policy / 自动改 Prompt / 自动改 Model Routing；critical proposal-only。
