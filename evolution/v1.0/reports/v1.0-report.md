# OpenCode Runtime Adapter & Deployment Governance Layer — v1.0 Report

> 阶段：v1.0 · **OpenCode Runtime Adapter & Deployment Governance Layer**
> 目标：MyTeam 已是 Agent Platform Source Repository，但缺少 Source → Runtime 部署管理层。历史上部分文件直接改 `C:\Users\Administrator\.config\opencode\`，导致边界模糊、来源不可追踪、回滚困难、多环境同步困难。v1.0 建立受治理部署链路：`MyTeam Source → Build → Runtime Adapter → Migration → Approval → OpenCode Runtime`。
> 升级前基线：Agent=30 MCP=5 Skill=26 Workflow=8（**不变**）
> 状态：完成（Adapter + Binding + Manifest + Migration/Rollback + Sync + 7 用例测试通过；**未自动安装、未改 runtime**）

## 1. Source / Runtime 分离架构

| 层 | 位置 | 角色 |
|---|---|---|
| Source of Truth | `MyTeam/source/` + `platform/` + `.ai/context/` | 唯一权威，开发在此 |
| Build | `build/package/...` | 从 source 构建安装包 |
| **Adapter** | `platform/runtime-adapter/` | source↔runtime 映射 + 部署治理 |
| Runtime | `C:/Users/Administrator/.config/opencode/` | 部署目标，开发期不直接改 |

**铁律（ra-1~ra-5）**：MyTeam=唯一 SoT；禁止 runtime 反向改 source；所有部署经 Package→Migration→Approval→Install；禁止自动安装/覆盖/升级/删除；drift 只报告不修复。

## 2. Adapter 设计

`platform/runtime-adapter/`（9 资产）：`adapter-schema.yaml`（映射契约 + 5 不变量 + forbidden）、`opencode-adapter.yaml`（集成边界）、`agent-binding.yaml`、`mcp-binding.yaml`、`skill-binding.yaml`、`deployment-manifest.yaml`、`migration-plan.yaml`、`rollback-plan.yaml`、`sync-state.yaml`。状态镜像 `.ai/context/runtime-adapter/adapter-state.yaml`。

## 3. Binding 机制

- **Agent Binding**：30 Agent 全覆盖，`platform_agent → runtime_agent + source_prompt + version + sha256 checksum`；version 对齐 version-registry（5 个 v2，其余 v1）。
- **MCP Binding**：5 MCP 只同步声明（不自动新增、不覆盖用户 mcp block）。
- **Skill Binding**：26 Skill 只同步引用（cc-switch 管理实体，不覆盖不删除）。

## 4. Migration 流程

`migration-plan.yaml`（手动）：`M1 build → M2 verify-baseline → M3 backup → M4 apply(platform-owned only) → M5 verify(hash) → M6 rollback(on fail) → M7 commit`。backup 先于 apply；verify 失败自动进 rollback；仅 status=approved 后人工触发。

## 5. Rollback 流程

`rollback-plan.yaml`：**复用 Recovery（strategy-registry / checkpoints）+ rollback/backups + v0.9 execution rollback**，不重设计。字段 `backup_ref / previous_version / restore_steps / verification`；guards 复用红线（不碰 skills/.opencode/.omo/node_modules）。
