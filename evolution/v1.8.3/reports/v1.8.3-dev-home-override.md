# MyTeam v1.8.3 Implementation Report — Home-as-Project 开发者自测 Bypass

> 阶段：v1.8.3 — **开发模式 bypass（`MYTEAM_ALLOW_HOME_AS_PROJECT`）**。
> 落点：`plugin/opencode/workspace-resolver.ts`（唯一被修改的源文件）。
> 新增测试：`plugin/opencode/tests/workspace-resolver-test.mjs`。
> 约束执行：保留 `HomeAsProjectError`；不改生产默认行为；不改 `guardHostWrite`；不改 OpenCode 配置。

---

## 1. 背景与目标

`workspace-resolver.ts` 现有安全规则：

```
project_root inside/equal myteam_home  =>  HomeAsProjectError
```

该规则用于阻止把 MyTeam Home（平台仓库根）当成用户项目，避免平台资产被当作项目 runtime。
**该规则必须保留。**

目标：增加**开发者自测能力**（在 MyTeam 仓库内启动 OpenCode 调试插件），
**但不能削弱生产隔离**。

## 3. 实现细节

### 3.1 新增开关

```ts
export function isHomeAsProjectDevAllowed(): boolean {
  return process.env.MYTEAM_ALLOW_HOME_AS_PROJECT === "1";
}
```

- **严格等于 `"1"`** 才开启（不做 `trim`，避免 `" 1 "`、`"1\n"` 等意外放行）。
- 任何其他取值（未设置 / `"0"` / `"true"` / `"yes"` / `""` / `" 1 "` / `"2"`）一律视为**关闭**。

### 3.2 解析分支（`resolveWorkspace`）

```ts
if (isInsideOrEqual(myteam_home, project_root)) {
  if (!isHomeAsProjectDevAllowed()) {
    throw new HomeAsProjectError(project_root, myteam_home,
      "project_root is inside or equal to myteam_home");   // 默认：生产行为不变
  }
  // dev override：仅“继续解析”。team_root 计算与写入边界完全不变。
}
const team_root = path.join(project_root, ".team");
```

关键点：bypass **只改变“是否抛错继续”**，不改变 `project_root` / `team_root` 的推导，
也不授予任何写权限。

### 3.3 写入边界守卫（`guardTeamWrite`，defense-in-depth）

```ts
export function guardTeamWrite(res: Resolution, targetPath: string): void {
  if (isInsideOrEqual(res.team_root, targetPath)) return;              // 仅允许 .team/**
  if (isInsideOrEqual(res.myteam_home, targetPath))
    throw new MyTeamResolutionError("...refused write to MyTeam Home platform asset...");
  throw new MyTeamResolutionError("...refused write outside project runtime (.team)...");
}
```

并在 `ensureTeamRoot` 的**每个实际写入目标**（`tRoot`、各子目录、`context.yaml`）前调用，
确保即使处于 bypass 模式，runtime 数据也只能写 `<project_root>/.team`，
**绝不可能写入 Home 平台资产**。
