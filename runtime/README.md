# Runtime Layer

Runtime describes the OpenCode install target and runtime templates. This layer is
**never modified during development**.

## Contents
| Path | Purpose |
|------|---------|
| `templates/` | Runtime install templates (config fragments, expected structure) |

## Install Target
```
C:\Users\Administrator\.config\opencode\
```

## Planned Install Contract
- prompts → `prompts/`
- docs → `docs/`
- workflows → `workflows/`
- config fragment → merged into `opencode.json` (`agent` block)

The install plan is generated by `build/scripts/build-package.ps1` and reviewed
before any manual execution. There is no auto-install in v0.6.2.
